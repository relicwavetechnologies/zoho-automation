Every part of the desktop moat, explained

Streaming timeline

Every thought and tool call appears live with a spinner, then settles to a check with its result. When the answer lands, the whole work log folds into a single "Worked for 14.2s" line you can re-open.

Live terminal · desktop-only

Divo can run real shell commands on your machine — crawl placements, run a script, check a repo — streaming output line by line. Gated by a per-command Run / Decline, with a hard denylist.

Cursor-grade markdown

Shiki-highlighted code, GFM tables, warm inline code, streaming-safe rendering. Block-memoized so a long answer streams as fast as the model writes it.

Approval gates

Outward-facing actions surface a card with the exact details — recipient, amount, file — and Approve / Decline. Decline tells Divo why, so it adapts instead of retrying.

Workspaces

Each client or project is a workspace with its own folder context and threads. Divo runs commands in the right directory and keeps each account's memory separate.

Data cards

Tool results that are tabular — rankings, placements, invoices — render as compact cards inline, not as walls of raw JSON.

Why desktop is the moat over chat

Divo already lives in Lark. Hermes upgrades desktop into the execution control plane: present, OS-privileged, and able to act locally. Terminal is shipped; hotkeys, capture, and file-screen context complete the native moat in the first rollout window.

Local execution shipped

Run scripts, crawlers, and tools on the user's own machine — never the server. The link-verification crawl above runs locally.

Global hotkey + capture planned

Summon Divo from any app in <1s; send selected text or the clipboard as context. Sub-2-second capture is what makes a tool a reflex.

Screen & file context planned

"Check the draft on my screen," "read this folder of briefs." The app sees what you see, with per-action approval.

Menu-bar + notifications planned

The surface for proactive agents — ranking drops, dead links, overdue invoices — as native alerts you can act on.
