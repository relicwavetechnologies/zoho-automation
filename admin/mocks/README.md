# Mocks

Standalone HTML prototypes. Open them from disk.

They live here rather than in `public/` because everything in `public/` is
copied verbatim into the production build and served without authentication —
and these carry real colleagues' addresses, written that way to make a pitch
feel true. A prototype is worth showing to people you choose; it is not worth
publishing.

The React equivalent is at `/preview/mail`, mounted in development builds only.
