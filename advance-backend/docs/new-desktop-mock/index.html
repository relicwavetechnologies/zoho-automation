How it plugs in
Channel split
One engine, two skins
Every chat lands in the same OrchestrationEngine. The Lark webhook and the new /desktop route both call engine.handle(incoming). incoming.channel is 'lark' or 'desktop'.
Status events
Different vocabulary per channel
StatusChannel.emit() branches on channel. Lark gets card updates; desktop gets streaming JSON events (tool.start, tool.progress, file.write, approval.required).
Transport
WebSocket from frame 04 onward
Tauri renderer opens a JWT-authenticated WS to the existing desktop-ws.gateway.ts. Tokens are issued by desktop-auth.routes.ts after Lark OAuth completes via the deep-link / polling fallback.
