One timeline: text, thoughts, and command cards interleaved in the exact order they happened. Each command appears once (no raw JSON row). Mid-run prose sits next to the command it describes.

How — collapse 3 zones into 1 ordered timeline

// Replace { activity[], terminals[], content } on the assistant message with
// ONE ordered list, appended in WS-event arrival order:
type TimelineItem =
  | { kind: 'text';    text: string }      // streamed markdown segment (prose / answer)
  | { kind: 'thought'; text: string }      // thinking narration segment
  | { kind: 'terminal'; block: TerminalBlock } // runCommand → rich card (shown ONCE)
  | { kind: 'tool';    row: ToolRow }       // non-terminal tools (web search, etc.)
  • Append in order: each event pushes or extends the last timeline item. Consecutive text deltas extend the open text segment; a terminal/thought/tool closes it and starts a fresh segment after — so prose stays where it was emitted.
  • De-dupe: a call_tool / tool.* event whose tool is runCommand is suppressed — the terminal.exec.request already produces the card. No more raw Ran {json} rows.
  • Top shimmer: “Working for Ns” while streaming → “Worked for Ns” when done; the whole timeline is collapsible under it (Cursor-style), final answer is just the last text segment.
  • Backend: already emits the right events; this is purely a client store + render change (store/chat.ts reducer → MessageBubble renders timeline in order instead of 3 zones).
