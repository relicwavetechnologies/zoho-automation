Divo — Message Bubble UX Pitch

Interactive mock · Lark dark theme · All run states

No code changes — design proposal only

What we can build

Your backend already tracks phases, plan steps, tool activity, and result previews (progress-state.ts → buildStatusCard). The gap is visual structure in Lark cards — not data. This pitch turns the same timeline into scannable, state-aware bubbles users trust.

Structured plan rail

Checklist with running spinner, done summaries, and failed steps — not plain [run] lines.

Live activity strip

One prominent “now doing” row with tool family badge (Zoho / Lark / Google) + elapsed time.

Result chips per step

Inline preview when a tool finishes: “12 invoices · ₹4.2L total” instead of raw log text.

Collapsible trace

Recent activity collapsed by default; expand for power users. Keeps the bubble short during long runs.

HITL & actions

Approval gates get primary/danger buttons in-card; scheduled runs show lock/wait state.

Final reply upgrade

Answer first, optional mini-table for tabular tool output, collapsible execution trace at bottom.

Message bubble lifecycle

One ephemeral card updates in-place during the run, then is replaced (or morphs) into the final answer.
