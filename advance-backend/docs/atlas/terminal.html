Terminal Execution

Give Divo a real shell — but never silently. Every container run is gated by a Run / Decline card in the chat. Approve and it spins up, streaming a live terminal. Decline and the agent is told, in its own context, that you said no — then it stops and offers you auto-mode if you'd rather not be asked again.

The run-gate & its escape hatches

A local, in-chat decision — fast, not the org manager-approval flow. Three modes:

Ask every time Default

Each command renders a Run / Decline card before the container starts. Nothing executes until you click.

Skip for this chat

A checkbox on the card. Choosing it stops asking for the rest of this thread — handy mid-task once you trust the run. Resets next thread.

Auto-run mode

Thread-level toggle (and a global default in settings). Divo runs without asking — Cursor's YOLO mode. Net access + destructive commands still gate even here.

What "Decline" does

Declining is not a silent no-op — the agent learns about it and adapts.

You click Declineon the run-gate card
→
Tool returns declinedno process ever spawns
→
Conversation gets a note"declined by user" — AI sees it
→
Execution stopsagent offers auto-run / skip
The decline is fed back as the tool result the model reads: declined: The user declined to run "npm test". Do not retry; ask what they'd prefer or offer auto-run. Because it lands in the conversation array, the agent's very next turn already knows it was refused — it won't blindly retry, and it can explain what the command would have done instead.

The runCommand tool

Standard Tool<TArgs,TOut> contract; the gate lives in execute() before any spawn.

typescript
// tools/families/run-command.tool.ts
const argsSchema = z.object({
  command:            z.string(),
  withInternetAccess: z.boolean().optional(),   // always gates, even in auto-run
  timeoutMs:          z.number().max(120000).optional(),
});

const resultSchema = z.object({
  status:     z.enum(['completed', 'declined']),
  exitCode:   z.number().optional(),
  stdout:     z.string().optional(),
  stderr:     z.string().optional(),
  durationMs: z.number().optional(),
});

async execute(args, ctx) {
  const mode = await getRunMode(ctx.runContext.chatId);   // 'ask' | 'auto'
  const mustGate = mode === 'ask' || args.withInternetAccess || isDestructive(args.command);

  if (mustGate) {
    const decision = await ctx.requestRunApproval({
      command: args.command, cwd: workspacePath, net: !!args.withInternetAccess,
    });
    if (decision.kind === 'decline') {
      return ok({ status: 'declined' });          // → "declined by user" tool result
    }
    if (decision.remember === 'chat') await setRunMode(ctx.runContext.chatId, 'auto');
  }
  // spawn in cwd, stream terminal.* events, return { status:'completed', exitCode, … }
}

WebSocket events — the approval handshake

The gate is a request/response over the same socket, then the live stream.

terminal.approvalserver → client. { callId, command, cwd, net } — renders the Run / Decline card.
terminal.decisionclient → server. { callId, decision: 'run'|'decline', remember?: 'chat' } — resolves the gate.
terminal.startserver → client. { callId, command, cwd, net } — only fires after a run decision.
terminal.output{ callId, data, stream } — live stdout/stderr, debounced.
terminal.end{ callId, exitCode, durationMs } — panel rolls into an activity row.
terminal.declined{ callId } — confirms the decline so the client renders the note + auto-run offer.

Net access always gates, even in auto-run. Auto-mode covers ordinary local commands; internet access and destructive patterns (rm -rf, git push, curl | sh) re-arm the Run / Decline card no matter what.

Guardrails

  • Nothing runs un-gated — Phase 1 ships the Run / Decline card on; auto-run is opt-in per thread.
  • Decline is legible to the agent — returned as the tool result, so the next turn already knows and won't retry.
  • Workspace-pinned cwd — cwd re-asserted per call; the model can't cd out.
  • Timeout + output cap — hard kill ≤120s, output truncated with a flag.
  • Env scrub + denylist — secrets stripped; fork bombs / disk wipes short-circuit before spawn.
  • Full audit — command, decision, who decided, exit code, net flag → orchestration tracer.
