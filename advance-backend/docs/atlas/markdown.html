Design decisions

Warm inline code

Cursor-style peach: bg hsl(28 50% 15%) + fg hsl(28 90% 72%). Reads as code without the heavy gray chip.

Shiki code blocks

vitesse-dark theme, 14 languages preloaded. Header shows the language + a copy button. Background neutralised to match our palette.

Minimal tables

No zebra, no header fill — bold white header text, hairline borders, rounded wrapper. Matches Cursor's calm tables.

Streaming-safe

Odd number of ``` fences? We append a synthetic close so a half-arrived code block stays highlighted instead of dumping raw text.

Envelope stripping

The supervisor wraps output in an [Execution] / [Reply] envelope. The activity stream already shows tool calls, so the renderer keeps only the reply body.

typescript
// Markdown.tsx — keep only what follows [Reply]
function stripProtocolEnvelope(content: string): string {
  const m = content.match(/\[Reply\][:\s]*/i);
  if (m) return content.slice(m.index + m[0].length).trimStart();
  if (/\[Execution\]/i.test(content)) return ''; // stream not at reply yet
  return content;
}
