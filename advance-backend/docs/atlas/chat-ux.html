The three behaviours

Full-width bubble

User messages span the same 720px column as Divo's reply — elevated card surface, rounded, multi-line. Not a right-aligned chat bubble.

Sticky pinning

position: sticky; top: 0 per turn with a solid full-width backdrop. Scrolled content is fully occluded — the next turn pushes the old pin out from the top.

Auto scroll-room

On send, the new turn gets min-height = viewport − bubble, then scrollIntoView pins it to the top so the work area gets a full screen below.

Turn grouping

Messages reduce into turns in the store; the list renders one TurnSection each.

typescript
// MessageList.tsx — group consecutive messages into turns
function groupTurns(messages: ChatMessage[]): Turn[] {
  const turns: Turn[] = [];
  let current: Turn | null = null;
  for (const m of messages) {
    if (m.role === 'user') {
      if (current) turns.push(current);
      current = { user: m, responses: [] };
    } else if (current) {
      current.responses.push(m);
    }
  }
  if (current) turns.push(current);
  return turns;
}
