Row lifecycle

StateBehaviour
runningVerb shimmers (gradient sweep). Only the newest active row shimmers at a time.
doneVerb swaps to past tense (Reading → Read), duration badge appears, expandable chevron if there's raw output.
errorVerb turns red, the arg shows the error message.
collapsedOn first reply token the whole stream folds to Thought for Ns. Click to re-expand and inspect every step + raw JSON.

Rolling window

Long runs used to grow unbounded down the page. Now they roll.

While working

Rows render in a fixed 168px viewport with a top fade. New rows auto-scroll into view; old ones roll up behind the gradient. The page never jumps.

When done

Collapses to a single pill. Expanding drops the height cap and shows the full history — every thinking line, every tool call, every raw payload.

WebSocket event schema

Every frame is { type: 'chat.event', requestId, event }. The event.type values:

thinking{ text } — model reasoning narration, drives a "Thinking" row (suppressed once reply streams).
tool.start{ callId, name, family, args, verb } — opens a shimmering tool row.
tool.end{ callId, ok, output, durationMs, past } — commits the row, swaps to past tense, attaches raw output.
text{ data } — user-facing reply delta. First one collapses the stream.
done{ message } — persisted assistant message; stream finalises.
error{ data } — run failed; surfaced as a system pill.
